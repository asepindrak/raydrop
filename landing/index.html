Engineering Excellence

Built for Maximum Throughput & Zero Friction

Designed with Rust and Tauri for near-zero memory footprint and raw multi-threaded socket acceleration.

Parallel IDM Slicing

Large files are dynamically sliced into 512KB binary chunks and transferred concurrently across 6 parallel worker streams, fully saturating multi-gigabit connections.

Smart Auto-Resume

Wi-Fi drops out or PC gets rebooted? Raydrop tracks chunk bitmaps in local SQLite. When the peer reconnects, transfers resume right from the exact byte without data loss.

End-to-End Encryption

Every session derives temporary keys via X25519 ECDH + HKDF-SHA256. Payload chunks are authenticated using ChaCha20-Poly1305 with BLAKE3 cryptographic integrity hashes.

Multi-NIC LAN Discovery

Detects all physical and virtual network adapters (Wi-Fi, Ethernet, VPN), automatically ranking and connecting via the fastest direct subnet in under 10 milliseconds.

Win 11 Direct Right-Click

Seamless 1-click Windows 11 integration bypasses the collapsed "Show more options" menu. Right-click any file or folder and click "Send with Raydrop" immediately.

In-App 1-Click Updater

Automatic background update notifications. Users can upgrade their desktop app directly with a single click, with real-time download speed and automated setup restart.

Zero Server Data Storage

Absolute Privacy By Architecture

Our signaling server (stun.raydrop.web.id) acts purely as a handshake coordinator. Files are never received, stored, or indexed on the server.

Zero File Uploads to the Cloud

Files travel directly from Peer A's hard drive to Peer B's hard drive through encrypted direct TCP / QUIC sockets. Even if someone intercepts the signaling server database, no file names, hashes, or bytes exist there.

BLAKE3 + ChaCha20-Poly1305 Security

Each transmission is protected with modern cryptographic primitives. Data tampering or bit-rot is immediately detected and discarded at chunk boundaries.

NETWORK ROUTING FLOW Zero-Trust

1. Discovery: mDNS probe (LAN) + STUN reflex (WAN)

2. Signaling: wss://stun.raydrop.web.id (Handshake)

3. ECDH: Ephemeral X25519 Key Agreement

4. Direct TCP: Peer-to-Peer 6-Stream Socket

5. Verification: BLAKE3 Chunk Checksum Validation
