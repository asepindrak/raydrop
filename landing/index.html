Transfer files in 3 simple steps

No Google Drive upload limits, no mandatory sign-ups, no speed throttling.

  1. 1

    Select Files or Right-Click

    Drag and drop any files into Raydrop, or directly right-click any file in Windows 11 File Explorer and select Send with Raydrop.

  2. 2

    Pick Target Computer

    Devices on the same Wi-Fi or LAN are automatically discovered via mDNS. For remote transfers (WAN), simply enter the target device code.

  3. 3

    Direct Instant Transfer

    Files stream directly peer-to-peer at your maximum Wi-Fi or LAN cable bandwidth. File integrity is verified in real-time with BLAKE3.

Built for Speed & Privacy

Modern peer-to-peer file transfer engineered for security, speed, and simplicity.

  • Zero Cloud Storage & 100% Privacy

    Your files are never stored, cached, or uploaded to any cloud server. The signaling server only assists initial peer connection via STUN/UDP.

  • Maximum Gigabit Speed

    No speed throttling or daily quotas. Maximize your full gigabit LAN cable bandwidth (up to 110+ MB/s) or high-speed Wi-Fi 6 network.

  • Cryptographic BLAKE3 Verification

    Every chunk is verified cryptographically using the ultra-fast BLAKE3 hashing algorithm, guaranteeing files arrive 100% intact without corruption.

  • Auto-Resume & Fault Tolerant

    Wi-Fi dropped or laptop went to sleep? Transfer automatically resumes from the last completed chunk without starting over from 0%.

  • Native Windows 11 Right-Click

    Native Windows 11 context menu integration. Just right-click any file directly without needing to hold Shift or open extra menus.

  • In-App 1-Click Auto Update

    Automatically checks for new releases on GitHub and lets you upgrade directly from within the app with a single click.

  • Encrypted P2P Chat & Media Sharing

    Directly chat with contacts using rich Markdown and code formatting. Send photos, videos, documents, and multiple files right inside chat without any server database storage.
